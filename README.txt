VoiceOfCardsBoB-Translation
===========================

Purpose
-------
This project contains the translation resource tool and the final single-file Windows patcher for Voice of Cards: The Beasts of Burden.
The translation workflow uses the game's English slot as the target slot.

Project layout
--------------
OriginalGameFiles\
    Original game resources used as read-only source files.

Translation\
    Translator-facing CSV files:
      scenario.csv
      card_name.csv
      card_desc.csv
      system.csv
      localization_system.csv

GeneratedGameFiles\
    Generated replacement game resources. The localization tool writes:
      asset_text_en
      localization-string-tables-english(en)_assets_all.bundle

SourceCode\VoiceOfCardsBoB-Translation\
    Source code for the translation resource tool.

SourceCode\VoiceOfCardsBoB-Patcher\
    Source code for the final Windows patcher.

Release\
    Final published patch EXE. No intermediate Build directory is used.

VoiceOfCardsBoB-Translation.slnx
    Solution containing both C# projects.

Translation CSV format
----------------------
Each CSV contains four columns:
    Key | English | Japanese | Target

Target is initialized from English. Edit only Target.
Newlines inside text remain real newlines inside quoted CSV cells and are not converted to literal \\n text.

Translation tool
----------------
The translation tool targets .NET 10 / C# 14 and uses AssetsTools.NET 3.0.5.
Run VoiceOfCardsBoB-Translation or run.bat from the project root.

Menu option 1 reads OriginalGameFiles and generates the five CSV files in Translation.
Menu option 2 reads Translation and generates replacement resources in GeneratedGameFiles.

Game replacement locations
--------------------------
GeneratedGameFiles\asset_text_en replaces VoiceofCardsTheBeastsofBurden_Data\StreamingAssets\Windows\asset_text_en
GeneratedGameFiles\localization-string-tables-english(en)_assets_all.bundle replaces VoiceofCardsTheBeastsofBurden_Data\StreamingAssets\aa\StandaloneWindows64\localization-string-tables-english(en)_assets_all.bundle

Patcher
-------
The patcher embeds the files from GeneratedGameFiles into one self-contained win-x64 EXE.
Before publishing the patcher, run the translation tool option 2 so both required GeneratedGameFiles exist.
Publish SourceCode\VoiceOfCardsBoB-Patcher\VoiceOfCardsBoB-Patcher.csproj in Release mode. Its PublishDir is configured directly to Release\.

The final VoiceOfCardsBoB_CN_Patch.exe is intended to be placed directly beside VoiceofCardsTheBeastsofBurden.exe.
It provides two operations: apply and restore.

Apply performs a global preflight check first. If any mapped target already has a .backup file, nothing is changed and the user is told to restore first. If preflight succeeds, each original target is renamed to target.backup and the embedded replacement is written to the original path.
Restore restores every mapped .backup file and reports every missing backup.
The patcher normally runs without administrator privileges. If the game directory is not writable, it restarts itself through Windows UAC with the requested apply/restore action.

Notes
-----
The current replacement set contains the two game files generated by the translation tool. catalog.json CRC handling is not included in this project version yet.
Fonts, language-specific images, chapter-title textures/prefabs, manuals, videos and other special resources are separate work and are not modified here.
